# network_modeling_project

Proyecto de Modelación de Sistemas en Redes: *El Escape de los Coleccionistas en el Metro de París*.

El enunciado está en [`docs/enunciado-proyecto.md`](docs/enunciado-proyecto.md) (PDF original en [`docs/enunciado-proyecto.pdf`](docs/enunciado-proyecto.pdf)).

## Cómo ejecutarlo

Requiere Python 3.10 o superior y no importa ninguna librería (ni siquiera la estándar).

```
python metro_escape.py
```

Lee `input.txt` y escribe `output.txt`, ambos en la misma carpeta que el programa.
